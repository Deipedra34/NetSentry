Create the first admin account

Dashboard authentication is enabled, but no user accounts exist yet, so the dashboard is locked. NetSentry never ships a default account: create the first admin from the command line on the machine running NetSentry.

Native install

python main.py --create-user YOUR_NAME --role admin

Docker

docker compose exec netsentry python main.py --create-user YOUR_NAME --role admin

You'll be asked for the password twice (it's never accepted as an argument). Then reload this page to sign in.
